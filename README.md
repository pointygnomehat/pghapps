## About

PGH Apps is a small software consulting firm. We work directly with clients to scope, build, and maintain software, from internal tools and integrations to customer-facing web and mobile applications. Engagements are handled by the same people from first conversation through delivery and support.

## Services

| Area | What it covers |
|---|---|
| **Custom application development** | Web applications, mobile apps, and internal tools built to a defined scope. |
| **Systems integration** | Connecting existing systems through APIs, including Google Workspace, payment processors, CRMs, and databases. |
| **Cloud and infrastructure** | Deployment, hosting, CI/CD pipelines, monitoring, and cost review on major cloud platforms. |
| **Data and automation** | Data pipelines, reporting, scheduled jobs, and automation of manual workflows. |
| **Technical assessment** | Code and architecture reviews, security and dependency audits, and modernization plans for legacy systems. |
| **Maintenance and support** | Ongoing updates, bug fixes, dependency upgrades, and on-call support under a retainer. |

## How We Work

1. **Discovery.** Define the problem, constraints, users, and success criteria. The output is a written scope and estimate.
2. **Design.** Agree on architecture, data model, and interface before writing production code.
3. **Build.** Short iterations with working software reviewed at the end of each one.
4. **Deliver.** Deploy to production, hand over documentation and credentials, and transfer ownership of all code.
5. **Support.** Optional ongoing maintenance, monitoring, and feature work.

Clients own the code and infrastructure we build for them. Repositories, cloud accounts, and domains are created under the client's accounts wherever possible.

## Technology

We select tools based on the client's existing systems and team. Common choices include:

- **Languages:** TypeScript/JavaScript, Python, Go, Java, Swift, Kotlin
- **Frontend:** React, Next.js, Vue
- **Backend:** Node.js, Django, FastAPI, Spring
- **Data:** PostgreSQL, MySQL, Redis, BigQuery
- **Cloud:** Google Cloud, AWS, Azure
- **Tooling:** Docker, Kubernetes, Terraform, GitHub Actions

## Engagement Models

- **Fixed scope:** a defined deliverable with an agreed price and timeline.
- **Time and materials:** billed hourly or daily, suited to evolving requirements.
- **Retainer:** a reserved block of monthly hours for maintenance and ongoing development.

## Repositories

Public repositories in this organization include open-source utilities, sample code, and project templates. Client work is kept in private repositories unless the client chooses otherwise.
